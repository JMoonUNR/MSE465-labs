# MC Lab B files

- `MSE465_MC_LabB_STUDENT.ipynb`: the student notebook.
- `openmc/`: OpenMC 0.16.0 for Colab (prebuilt for Ubuntu 24.04 and 22.04) and its Python wheel. If no prebuilt copy fits the machine, the notebook builds OpenMC 0.16.0 from source (about 3 minutes).
- `data/`: the six nuclear data files the lab uses (ENDF/B-VII.1, about 9 MB).

Keep the folder names as they are: the notebook downloads from `labB/openmc/` and `labB/data/`.
